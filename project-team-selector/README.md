# Project Team Selector

# Отчёт по лабораторной работе №1

## Тема проекта

**Программный модуль подбора участников проекта по правкам и интересам.**

## Цель проекта

Разработать минимальный запускаемый каркас веб-приложения для хранения информации об участниках проекта и их интересах с использованием HTML, CSS, JavaScript и localStorage.

## Используемый стек

- HTML5
- CSS3
- JavaScript (ES6)
- localStorage
- Git
- GitHub

## Использование ИИ

В качестве ИИ-помощника использовался ChatGPT через веб-интерфейс. С помощью ИИ была разработана структура проекта, созданы файлы `index.html`, `style.css`, `script.js`, `.gitignore` и `README.md`, а также получены рекомендации по настройке Git и публикации проекта на GitHub. После генерации код был проверен и протестирован вручную.

## Структура проекта

- `index.html`
- `style.css`
- `script.js`
- `.gitignore`
- `README.md`

## Команда запуска

Для запуска проекта необходимо открыть файл `index.html` в любом современном веб-браузере.

## Результат выполнения

Создан минимальный веб-проект, позволяющий добавлять участников проекта и их интересы. Данные сохраняются в localStorage, поэтому после обновления страницы информация не теряется. Проект успешно запускается локально и опубликован в удалённом репозитории GitHub.
