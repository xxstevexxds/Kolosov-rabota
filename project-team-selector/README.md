# Отчёт по лабораторной работе №2

## Название ветки

**feature/first-feature**

## Реализованный пользовательский сценарий

Добавлена функция удаления участника проекта из списка. После удаления изменения автоматически сохраняются в localStorage и остаются после перезагрузки страницы.

## Изменённые файлы

- `script.js` — реализована функция удаления участников и обновление списка.
- `style.css` — добавлено оформление кнопки «Удалить».
- `README.md` — обновлено описание проекта и информация о выполненной работе.

## Сценарий до изменений

Пользователь мог только добавлять участников проекта.

## Сценарий после изменений

Пользователь может добавлять и удалять участников проекта. Все изменения автоматически сохраняются в localStorage.

## Ручные проверки

1. Добавить нового участника.
2. Удалить участника кнопкой «Удалить».
3. Обновить страницу и убедиться, что изменения сохранились.

## Возможная ошибка пользователя

Попытка добавить участника с незаполненными полями. В этом случае приложение выводит сообщение «Заполните все поля» и не создаёт запись.

## Работа с Git

- Создана ветка **feature/first-feature**.
- Изменения просмотрены с помощью команды `git diff`.
- Выполнен коммит с сообщением `feat: add participant deletion`.
- Выполнено слияние ветки с `main` командой `git merge feature/first-feature` (**способ слияния — merge**).
- После объединения изменений проект повторно проверен и отправлен в GitHub.
