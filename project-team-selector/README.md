# Отчёт по лабораторной работе №2

## Название ветки

**feature/first-feature**

## Реализованный пользовательский сценарий

Добавлена возможность удаления участника проекта из списка. После удаления изменения автоматически сохраняются в localStorage и остаются после перезагрузки страницы.

## Изменённые файлы

- script.js
- style.css

## Сценарий до изменений

Пользователь мог только добавлять участников проекта.

## Сценарий после изменений

Пользователь может добавлять участников, удалять их и хранить актуальный список между запусками приложения.

## Ручные проверки

1. Добавить нового участника.
2. Удалить участника кнопкой «Удалить».
3. Обновить страницу и убедиться, что изменения сохранились.

## Возможная ошибка пользователя

Попытка добавить участника без заполнения полей. В этом случае приложение выводит предупреждение и не добавляет запись.

## Работа с Git

- Создана ветка `feature/first-feature`.
- Изменения проверены с помощью `git diff`.
- Выполнен коммит с сообщением `feat: add participant deletion`.
- Выполнено слияние ветки с `main`.
- Изменения отправлены в удалённый репозиторий GitHub.

## Обнаруженная проблема

После реализации функции была проверена корректность удаления участников и сохранения данных в localStorage после обновления страницы.
